# Rust
AOC solutions in rust

## Util
Use `cargo r --bin create` to automatically create boilerplate!
Usage:
```
cargo r --bin create -- [YEAR] [DAY]
```

Don't forget to change `create.rs` every year...

## Tools
```
cargo r --bin lfify
```
Turns CRLF -> LF

```
cargo r --bin cleanup
```
Remove `data.txt` files
